# Privacy Policy

**Application:** Spending Tracker (Family Budget Tracker)

**Maintainer:** [falconsag](https://github.com/falconsag)

**Last updated:** 16 October 2026

## Purpose and scope

Spending Tracker is a personal Python application intended to run on the maintainer's own computer for household budgeting and spending analysis. It is not a public financial service. It accesses only the maintainer's own or jointly held bank accounts, with the required account-holder authorization.

## Account information

With explicit bank authorization, the application may retrieve account identifiers, balances and transaction details, such as dates, amounts, currencies, payment descriptions and counterparties, through Enable Banking. This information is used only for personal household financial analysis.

Bank authentication takes place through the bank's and Enable Banking's authorization flow. Bank login credentials must not be collected or stored by this application. API private keys, authorization codes and session identifiers must be kept confidential.

## Storage, sharing and deletion

Downloaded information and analysis outputs are intended to remain on the maintainer's own device. They are not sold, used for advertising or published in this repository. Financial records, private keys and session credentials must never be committed to GitHub.

Local records are retained only as needed for household analysis and can be deleted manually, including any exports and backups. Revoking bank access prevents future retrieval subject to the provider's authorization rules; it does not delete previously downloaded records.

Enable Banking and the connected bank process information under their own terms and privacy notices. See [Enable Banking's Privacy Notice](https://enablebanking.com/privacy/). GitHub hosts these public documents and processes website visits under [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Contact

For privacy questions, use the maintainer's data protection email registered for this application in the Enable Banking Control Panel. Do not post account details, transactions or credentials in public GitHub issues.
